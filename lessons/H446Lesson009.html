Set the width

Eight bits hold 28 = 256 possible patterns. The signed range is −128 to +127.

Move −44 into the pattern range

−44 + 256 = 212. We now build the 8-bit pattern for positive integer 212.

Use remainder and quotient

Repeated % 2 gives each bit and integer / 2 gives the next value. The reverse-built string is 11010100.

Check by decoding

The MSB is 1, so 212 − 256 = −44. The code has modelled the two’s-complement rule.

Convert denary −44 to an 8-bit two’s-complement binary number. [1 mark]

Full .NET Fiddle Console model

using System;

public class Program
{
    public static int PowerOfTwo(int exponent)
    {
        int value = 1;
        for (int count = 0; count < exponent; count++)
        {
            value = value * 2;
        }
        return value;
    }

    public static string DenaryToTwosComplement(int value, int width)
    {
        if (value < 0)
        {
            value = value + PowerOfTwo(width);
        }

        string bits = "";
        for (int position = 0; position < width; position++)
        {
            int bit = value % 2;
            if (bit == 0) bits = "0" + bits;
            else bits = "1" + bits;
            value = value / 2;
        }
        return bits;
    }

    public static void Main()
    {
        Console.WriteLine(DenaryToTwosComplement(-44, 8));
    }
}

Output: 11010100

H446 coding extension — applies two’s complement and fixed-point representation
Complete .NET Fiddle Console model. [6 marks]
using System;

public class Program
{
    public static int PowerOfTwo(int exponent)
    {
        int value = 1;
        for (int count = 0; count < exponent; count++)
        {
            value = value * 2;
        }
        return value;
    }

    public static int TwosComplementToDenary(string bits)
    {
        int value = 0;
        for (int position = 0; position < bits.Length; position++)
        {
            int bit = int.Parse(bits.Substring(position, 1));
            value = value * 2 + bit;
        }
        if (bits.Substring(0, 1) == "1")
        {
            value = value - PowerOfTwo(bits.Length);
        }
        return value;
    }

    public static double FixedPointToDenary(string bits, int fractionBits)
    {
        return TwosComplementToDenary(bits) / (double)PowerOfTwo(fractionBits);
    }

    public static void Main()
    {
        string bits = "10110000";
        int signedValue = TwosComplementToDenary(bits);
        Console.WriteLine("Signed integer: " + signedValue);
        Console.WriteLine("Fixed-point value: " + FixedPointToDenary(bits, 4));
    }
}

Signed integer: -80 Fixed-point value: -5

Precision matters

Say it like a computer scientist

Say the missing term or definition before each click. One answer appears at a time.

Two’s complement
A binary method for representing positive and negative integers using a fixed number of bits.
Most significant bit (MSB)
The leftmost bit. In a two’s-complement value, it indicates whether the value is negative.
Signed integer
An integer representation that can store negative as well as positive values.
Fixed point
A representation where the binary point is in an agreed, unchanging position.
Fractional bits
The number of stored bits to the right of the implied binary point.
Scale factor
The power of two used to turn a stored fixed-point integer into its real value.
Range
The set of values a fixed number of bits can represent.
Precision
The smallest change in value that a representation can distinguish.
Sign extension
Adding copies of the MSB when increasing a two’s-complement number’s width.
