Question: Trace the program and explain how it creates, adds to, traverses and removes from a linked list. [6 marks]

Adapted from OCR H446/01 · June 2023 · Q2(c)(iv)
using System;
using System.Collections.Generic;

public class Program
{
    public static void Main()
    {
        LinkedList<string> route = new LinkedList<string>();
        route.AddLast("A");
        route.AddLast("C");
        route.AddAfter(route.First, "B");

        foreach (string stop in route)
            Console.Write(stop + " ");

        route.Remove("B");
        Console.WriteLine("\n" + route.Count);
    }
}

1 · Create and add

The list starts empty. AddLast creates A → C; AddAfter inserts B between them.

2 · Traverse

foreach follows the node links from first to last, outputting A B C.

3 · Remove safely

Removing B reconnects A to C. Two nodes remain, so Count outputs 2.

Trace the linked-list program and explain create, add, traverse and remove. [6 marks]

Output: A B C, then 2.

new LinkedList<string>() creates an empty list. AddLast adds A and C; AddAfter inserts B after the first node by changing links. foreach traverses from first to last. Remove("B") removes B and reconnects A to C, leaving two nodes.

Question: Complete the directed-graph adjacency list so it adds, traverses and removes an edge. [6 marks]

Adapted from OCR H446/01 graph-operation questions

Complete the methods

Completed code

graph["A"].Add("C");

    Console.WriteLine(neighbour);

The traversal outputs B then C. Removing B deletes the directed edge A → B.
