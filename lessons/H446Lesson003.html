Question: A school stores data for 30 students. Each student has a candidate number, name, extra-time status and four subject marks. Explain how records and arrays could be combined to represent this data. [6 marks]

Adapted from OCR H446/01 · June 2024 · Q8(a–b)

Model one student

Use a record because one student has several related fields with different data types.

Model repeated marks

Use a four-element integer array inside the record because the subject marks share one type.

Model the cohort

Store the 30 student records in an array so each student can be accessed and processed systematically.

A school stores data for 30 students. Each student has a candidate number, name, extra-time status and four subject marks. Explain how records and arrays could be combined to represent this data. [6 marks]
Start with what belongs together: one record describes one student; arrays handle repeated data of the same type.
Model response: Define a Student record with named fields such as candidateNumber (string), name (string), extraTime (Boolean) and marks (array of four integers). The record keeps the different pieces of data about one student together even though the fields use different types. Create an array of 30 Student records to represent the cohort. An index can then select a particular student, while a second index can select one of that student’s four marks. This makes it possible to traverse all students or all marks using iteration rather than writing separate code for every value.

Question: A journey-planning program stores an ordered sequence of stops. Users can insert and remove stops while planning. Explain why a list is more suitable than a tuple. [4 marks]

Adapted from OCR H446/01 · June 2023 · Q2(c)(ii–iii)

Weak answer

“A list is better because it can change.”

What is missing? Rewrite it as a developed comparison.

Possible improved answer

A list keeps the stops in an ordered sequence and can change size, so stops can be inserted or removed as the user edits the route. A tuple represents a fixed ordered group, so it is less suitable when the number of stops needs to change.

Push it further

A coordinate contains an x value and a y value that must stay together. Why might a tuple be suitable?

Answer

A tuple keeps the two coordinates together as one ordered pair. Its fixed structure is suitable because every location needs exactly two values, and each value can be accessed by its position.
