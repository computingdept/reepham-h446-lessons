Represent

Number basesBinary uses base 2. Hexadecimal uses base 16; one hexadecimal digit represents four binary bits.
Negative integersSign and magnitude stores a sign bit plus magnitude. Two’s complement is formed by inverting the positive value and adding 1.
Check the rangeAn 8-bit unsigned integer stores 0–255; 8-bit two’s complement stores −128–127.

Manipulate

Binary arithmeticAdd from right to left and carry. Subtraction can be completed by adding a two’s-complement negative.
Binary shiftsLeft shifts multiply by powers of two; right shifts divide positive values by powers of two. Discarded bits are lost.
Bit masksAND tests or clears bits · OR sets bits · XOR toggles bits.

Question: Represent denary −107 using 8-bit sign and magnitude and 8-bit two’s complement. Give one advantage of two’s complement. [3 marks]

OCR H446/01 · June 2023 · Q3(b)

Write positive 107

Use the 8-bit place values: 01101011.

Sign and magnitude

Keep the seven magnitude bits and change the sign bit to 1: 11101011.

Two’s complement

Invert 01101011 to 10010100, then add 1: 10010101. One advantage is that arithmetic is easier.

OCR H446/01 June 2023 Q3(b) — represent −107 in two signed formats and give an advantage. [3 marks]
Start once, then apply the rule for each representation.
Model response: +107 is 01101011. Sign and magnitude is 11101011. For two’s complement, invert 01101011 to 10010100, then add 1 to give 10010101. Two’s complement makes arithmetic easier and has only one representation of zero.

Keep the methods separate

  1. Write positive magnitude.
  2. Sign and magnitude: set sign bit.
  3. Two’s complement: invert and add 1.

Question: Convert −124 to 8-bit two’s complement, state another method for storing negative integers, and convert denary 298 to hexadecimal. [4 marks]

OCR H446/01 · June 2024 · Q4(a–b)

Incomplete answer

“−124 is 11111100; another method is negative binary; 298 is 12A.”

Identify the incorrect parts and rewrite the response using named methods and visible conversion working.

Mark-scheme response

−124: +124 is 01111100; invert and add 1 to obtain 10000100. Another accepted representation is sign and magnitude or one’s complement. 298 = 18×16 + 10 = 12A.

Check it

Which intermediate value should appear immediately before adding 1?

Answer

01111100 inverted is 10000011. Adding 1 gives 10000100.

Character sets [3]

Give one similarity and two differences between ASCII and Unicode.

OCR H446/01 · June 2022 · Q5(e)(ii–iii)
Mark points: both encode characters using binary; ASCII has 128/256 characters while Unicode has many more; ASCII is 7/8-bit and mainly Latin-based, while Unicode may use more bits and supports worldwide scripts and symbols.

Integer
A positive or negative whole number, including zero.
Real
A number that may contain a fractional part.
Character
One letter, digit or symbol.
String
A sequence of characters.
Boolean
A value with two states, normally True or False.
Sign and magnitude
The first bit stores the sign; remaining bits store magnitude.
Two’s complement
A signed binary system with one zero and arithmetic-compatible negatives.
Hexadecimal
A base-16 system using digits 0–9 and A–F.
Unsigned integer
A whole number representation with no negative values.
Binary shift
Moving all bits left or right by a stated number of places.
Bit mask
A bit pattern used with a bitwise operation to test or change selected bits.
ASCII / Unicode
Character sets that map characters to numeric codes; Unicode has far wider coverage.
