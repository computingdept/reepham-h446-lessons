Hexadecimal is also textA result such as "BD" contains a letter, so it must be a string.

2. Convert text into an integer

Tell C# which base to readUse base 2 for binary and base 16 for hexadecimal.int value = Convert.ToInt32(binaryText, 2);
Denary is the defaultFor denary text use Convert.ToInt32(denaryText).

3. Format an integer for output

Hexadecimal output"X" formats upper-case hexadecimal. "X2" keeps two digits, so five becomes 05.string hex = value.ToString("X2");
Binary outputUse base 2, then add leading zeroes for an 8-bit result.Convert.ToString(value, 2).PadLeft(8, '0')

Work with integersConvert both binary strings to integers, use + or -, then format the result back to binary.

Convert denary 189 to two-digit upper-case hexadecimal, beginning with the text "189". [3 marks]

Full .NET Fiddle Console model

using System;

public class Program
{
    public static void Main()
    {
        string denaryText = "189";
        int denary = Convert.ToInt32(denaryText);
        string hexadecimal = denary.ToString("X2");

        Console.WriteLine(hexadecimal);
    }
}

Output: BD

Why it works: it changes representations, not the value: "189" → 189 → "BD".

Build both operations [6]

Write a complete program using "00110111" and "00001101". Output labelled 8-bit sum and difference.

H446 coding extension — applies the conversion and arithmetic methods above
Write a complete program that outputs labelled 8-bit sum and difference. [6 marks]
using System;

public class Program
{
    public static void Main()
    {
        string first = "00110111";
        string second = "00001101";
        int firstValue = Convert.ToInt32(first, 2);
        int secondValue = Convert.ToInt32(second, 2);

        int sum = firstValue + secondValue;
        int difference = firstValue - secondValue;

        Console.WriteLine("Sum: " + Convert.ToString(sum, 2).PadLeft(8, '0'));
        Console.WriteLine("Difference: " + Convert.ToString(difference, 2).PadLeft(8, '0'));
    }
}

Sum: 01000100 Difference: 00101010

Precision matters

Say it like a computer scientist

Say the missing term or definition before each click. One answer appears at a time.

String
A sequence of characters stored as text, for example "10101111".
Integer
A whole-number data type used for arithmetic in C#.
Convert.ToInt32
A method that converts suitable text into an integer; an optional second argument gives the input base.
Base / radix
The number of symbols used by a number system: binary is base 2 and hexadecimal is base 16.
Format string
A code such as "X2" that controls how an integer is written as text.
Padding
Adding leading characters so output has a chosen width, for example 8 bits.
Overflow
When a calculation produces a value outside the range that can be stored in the available bits.
Nibble
A group of exactly four binary bits, represented by one hexadecimal digit.
Operand
A value used by an operator, for example the two values added by +.
